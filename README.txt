어디든, 나답게 — MBTI 여행 스타일 테스트

실행: ZIP 압축을 풀고 index.html을 브라우저에서 열어 주세요.
index.html, style.css, script.js를 같은 폴더에 유지해 주세요.
설치, 외부 라이브러리, 서버, 데이터베이스, 네트워크 연결이 필요하지 않습니다.
스마트폰은 HTML을 실행할 수 있는 브라우저/파일 앱으로 열어 주세요.

사용: 시작 → 16문항에서 답변 선택 후 다음 → 결과 확인.
이전 질문으로 이동해 답변 수정이 가능합니다.
결과의 다시 하기, 결과 공유하기, 결과 코드 복사, 동행 코드 비교를 이용할 수 있습니다.
최근 완료 결과는 localStorage가 허용되는 브라우저에 한 개 저장됩니다.
공유는 기기의 공유 기능 → 클립보드 → 수동 복사 창 순으로 지원합니다.
로컬 파일에서는 다른 기기가 접근할 수 없는 로컬 파일 경로를 공유하지 않습니다.
동행에게 동일한 테스트 ZIP과 결과 코드를 보내 주세요.

채점: E/I, S/N, T/F, J/P 각각 4문항. 선택마다 해당 성향에 1표.
2:2 동점은 해당 성향의 마지막(13~16번) 답변으로 결정합니다.
정식 MBTI 검사나 심리 진단이 아닌 여행 취향 탐색용입니다.

기획안 반영: 원문 12개 질문과 16유형 여행 캐릭터명을 사용했습니다.
사용자 필수 조건인 16문항에 맞춰 4문항을 추가하고 동점 규칙을 정의했습니다.
결과 설명과 이모지는 새로 작성했습니다.
